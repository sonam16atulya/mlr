 # Regression Analysis for Predictive Modeling

## Overview
Developed a predictive regression model on an anonymized dataset where feature identities were unknown. The objective was to analyze hidden relationships between predictors and the response variable using statistical modeling techniques and build an interpretable model.

## Approach

### Exploratory Analysis & Feature Evaluation
- Performed exploratory data analysis to understand predictor distributions and relationships
- Evaluated feature significance using General Linear Test statistics and Added Variable Plots

### Regression Diagnostics
- Assessed model assumptions including multicollinearity, heteroscedasticity, and non-linearity
- Identified and treated outliers, leverage points, and influential observations using DFFITS, DFBETAS, and Cook’s Distance

### Model Development
- Constructed higher-order regression models by incorporating interaction effects between predictors
- Applied forward and best subset selection techniques using Adjusted R², AIC, and BIC to select the optimal model

- Model Diagnostics

- Influence Analysis
